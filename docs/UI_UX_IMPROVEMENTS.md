### 修正した既存の不具合（一覧にない項目）

- `historyDB.getByEntity` が存在しないインデックス `entityId` を使っており、`SchemaError` になっていた
- `progressLogsDB.getByDate` が存在しない複合インデックスを使っており、進捗ページの記録も失敗していた
- 保存直後に `editorStore.currentScene` を再代入していたため、保存中に入力した文字が消える可能性があった（自動保存の間隔を短くする前提で修正）
- 別の作品を開いたとき、前の作品のシーンがエディタに残っていた

### スマホ向けに追加した機能

- キーボード上の補助バー（「」『』（）……――、ルビ、傍点、字下げ、元に戻す／やり直す、カーソル移動、前後のシーン）
- ボトムシート: 章・シーン一覧、参照（キャラクター／設定資料／メモ）、表示と書式、操作、目標
- タイプライタースクロール、今の段落以外を薄く表示（CSS Custom Highlight API 対応ブラウザのみ）
- 前回開いたシーンを自動で開く
- メモ（ネタ帳）。端末ごとの localStorage に保存し、同期はしない。「プロットへ」で未整理のプロットに変換できる

### 既知の制限・未対応

- 前後のシーンへの移動は、本文末尾のボタンで行う（引っ張る操作は未実装）
- スマホでは文字サイズを 16px 未満にしない（iOS の入力時の自動拡大を避けるため）
- iOS Safari の実機でのキーボード挙動（`visualViewport` の補正）は実機で未確認。Chromium での疑似確認のみ
- プロット・キャラクター・設定資料・進捗ページのスマホ向けレイアウトは、見出しの折り返しのみ対応

### 相関図キャンバス（2026-10-16）

B-7（相関図に線が描画されない）に対応。キャラクターページの「相関図」を、Svelte Flow（`@xyflow/svelte`）によるドラッグ操作のキャンバスに置き換えた。

- キャラクターのアイコンをドラッグして配置できる。ピンチで拡大縮小、スマホは「全画面」表示に対応
- 丸い点から別のキャラクターへドラッグすると、関係（例: 幼なじみ）を入力するシートが開く。線の取り込み範囲は広めにしてあり、タッチでも掴みやすい
- 線またはラベルをタップすると、関係名・色（6色）・線の形（曲線／直線／折れ線／角丸）を編集、削除できる
- 「＋ グループ」で枠を作り、名前・色を付けられる。枠はドラッグで移動すると中のキャラクターも動き、角でサイズを変えられる
- 関係の正は従来どおり `Character.relationships`（同期対象）。配置・グループ・線の見た目は IndexedDB の `relationMaps`（スキーマ v2）に端末ごとに保存し、同期はしない
- 同じ画面の「自動配置」で円形に並べ直せる

プロット・キャラクター・設定資料・進捗ページは、見出しの折り返しとスマホ向けの余白調整を行った。

- 本文のルビ・傍点の記法は `｜親《ルビ》`、`《《傍点》》` のみ対応
- 校正は簡易的なルール（正規表現）による。文脈を読んだ校正ではない
